# 方剂转写提示词（用于知识闪卡 App）

> 用法：把提示词与"一段教材原文"一起发给 AI（每次一个方剂片段），
> 将 AI 的输出保存为 `方名.md` 文件，按分类放入文件夹后导入 App 即可。
> 文件规范：文件名 = 方名；正文首行 `# 方名`；字段行 `字段：内容`。

---

你是一位中药方剂学数据整理助手。我会给你一段教材原文片段（一个方剂的完整条目），请严格按下面的格式与规则，将其转写为结构化 Markdown，供知识卡片软件使用。

## 一、输出格式（严格按此模板，不得增减、调换字段）

# 方名
来源：《书名》
组成：药名剂量、药名剂量、……
功效：……
主治：……

## 二、字段映射规则

1. **方名**：取原文条目标题（如“小柴胡汤”），写为一级标题 `# `。
2. **来源**：取原文中的出处（如《伤寒论》），保留书名号；原文未标注出处时写“来源：未注明”。
3. **组成**：取原文【组成】部分。保留药名与剂量（包括括注换算，如“半斤(24g)”）；炮制与煎煮注记（如“炙”“洗”“切”“擘”）保留并括注在药名后，如“半夏(洗)半升(9g)”；各项用顿号“、”分隔；不换算、不省略剂量。
4. **功效**：取原文【功用】或【功效】部分；原文写作“功用”时统一改写为“功效”。
5. **主治**：取原文【主治】部分。若原文分多条（如 1. 2. 3.），保留编号，每条独立一行；条文内的症状、舌苔、脉象等描述完整保留，不删减、不概括。

## 三、转换规则

1. 只输出上述五个字段；丢弃【用法】【证治机理】【方解】【运用】【附方】等其他一切内容。
2. 忠实原文：不增写、不改写、不合并或替换药名，不添加任何自己的解释或总结。
3. 输出为纯文本 Markdown，不要用代码块包裹，不要任何前言、解释或后记。
4. 若原文明显缺少某个字段（如无主治），该字段内容写“（原文未提供）”，不要自行编造。
5. 繁体字、异体字按原文保留；数字、单位保持原文写法。

## 四、示例

**输入：**

小柴胡汤
《伤寒论》
【组成】柴胡半斤(24g)黄芩三两(9g)人参三两(9g)甘草炙，三两(9g)半夏洗，半升(9g)生姜切，三两(9g)大枣擘，十二枚(4枚)
【用法】上七味，以水一斗二升，煮取六升，去滓，再煎，取三升，温服一升，日三服。
【功用】和解少阳。
【主治】
1.伤寒少阳证。往来寒热，胸胁苦满，默默不欲饮食，心烦喜呕，口苦，咽干，目眩，舌苔薄白，脉弦。
2.妇人中风，热入血室。经水适断，寒热发作有时。
3.疟疾、黄疸等病而见少阳证者。

**输出：**

来源：《伤寒论》
组成：柴胡(半斤(24g))、黄芩三两(9g)、人参三两(9g)、甘草(炙)三两(9g)、半夏(洗)半升(9g)、生姜(切)三两(9g)、大枣(擘)十二枚(4枚)
功效：和解少阳
主治：
1. 伤寒少阳证。往来寒热，胸胁苦满，默默不欲饮食，心烦喜呕，口苦，咽干，目眩，舌苔薄白，脉弦。
2. 妇人中风，热入血室。经水适断，寒热发作有时。
3. 疟疾、黄疸等病而见少阳证者。
