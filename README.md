# 知识闪卡（KnowledgeCards）

> 安卓离线知识卡片应用：把 Markdown 文件夹变成可滑动的知识卡片，多本书分架管理，带桌面微件。
> **KnowledgeCards — an offline Android flashcard app for Markdown knowledge bases.**

把一批约 150 字的文本卡片（如方剂学知识：来源/组成/功效/主治）按文件夹分类整理，导入后即可左右滑动复习，并可通过桌面微件直接查看当前卡片。

- 📚 **书架**：每次导入一个压缩包就是一本独立的书，目录/闪卡/微件只显示当前选中的书
- 🚫 无广告 · 无网络权限 · 纯本地离线
- 📱 中文界面，适配深色模式与多色主题

## 功能

| 模块 | 能力 |
|---|---|
| **书架** | 每次导入 `.zip` / `.tar` / Markdown 文件夹 = 一本独立的书（以文件名命名，同名则更新原书）；点书切换并进入其目录；重命名 / 删除整本书 |
| **闪卡浏览** | 只浏览当前书；左右滑动翻卡；目录顺序浏览（与目录页一致）；重启/微件联动恢复进度；切换书后回到第一张 |
| **闪卡集** | 目录页选中某个分类后，闪卡页只浏览该分类的卡片 |
| **目录** | 只显示当前书的多级分类树（展开动效）；卡组上移/下移/重命名/删除；**全书检索**（目录+卡片，命中高亮定位） |
| **导入** | SAF 选择文件夹递归导入 `.md`；支持 `.zip` / `.tar` 压缩包；按「书 + 路径 + 标题」判重，重复导入自动更新 |
| **导出** | 按「书 / 分类」生成文件夹结构的 .md 备份，可再次导入还原 |
| **编辑** | 修改标题/正文/分类（分类候选只来自当前书） |
| **设置** | 主题（跟随系统/浅色/深色）、8 套强调色、正文字号/微件字号、导入导出入口 |
| **桌面微件** | 跟随当前书；半透明圆角面板；标题栏显示「书名 · 分类」；展开/收起完整路径；正文可滚动；上一张/下一张按钮；与 App 实时双向同步 |

## 使用场景

以中医药教材为例：把教材内容用 AI 转写为每张约 150 字的卡片，一个压缩包一本教材

```
中药学.zip  ──导入──▶  书架《中药学》
├── 1.解表药/
│   ├── 发散风寒药/
│   │   ├── 麻黄.md      ← # 麻黄
│   │   └── 桂枝.md        来源：…
│   └── 发散风热药/        性味：…
└── 2.清热药/              功效：…
方剂学.zip  ──导入──▶  书架《方剂学》
```

「书架」页每行是一本书（卡片数 / 目录数 / 导入日期），点一下即可切换：
目录页、闪卡页和桌面微件都只显示当前这本书的内容。

## 导入格式

- 一次导入 = 一本书：`.zip` / `.tar` 用文件名当书名，Markdown 文件夹用文件夹名当书名
- 同名再导入会在原书上更新（不会产生第二本），想分开就改文件名
- 一个 `.md` 文件 = 一张卡片
- **分类 = 文件所在文件夹的层级**（`解表剂/辛温解表/麻黄汤.md` → 分类「解表剂/辛温解表」）
- 标题：文件名；文件内第一个非空行为 `# 标题` 时以文件内为准
- 正文：其余所有行

## 构建

- 环境：JDK 17+、Android SDK；本仓库不含本机路径，JDK 通过 `JAVA_HOME` 指定
- 设备要求：**Android 16（API 36）及以上**（minSdk 36）

```bash
./gradlew :app:assembleDebug   # 构建 debug APK（约 40MB）
./gradlew :app:installDebug    # 安装到已连接设备
./gradlew :app:assembleRelease # 构建发布版 APK（R8 裁剪，约 5MB）
```

单元测试：`./gradlew :app:testDebugUnitTest`

## 技术栈
